iCloud Live Previews: key screens

Nine moments across Mac, iPad and iPhone, from a folder of blank icons to search inside scans. Every frame is drawn by the same code as the live prototype.

Concept · not an Apple product

Show the file, not the format

Every file carries a real preview that syncs like a name or a date, so a cloud badge never hides what something is.

Download is a choice

Opening streams a light preview. The original arrives only when someone asks for it, with its size on the button.

Say the cost first

On cellular, the data a download will use is shown against the month's plan before anything moves.

Private by construction

Previews are made on the device that saved the file and encrypted with its keys, so Advanced Data Protection still holds.
